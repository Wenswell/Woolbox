# Records 审计与列表计划

状态：进行中

## 范围

- 网页 `Entries` 只保留筛选和批量删除，不提供流水编辑。
- 服务端为每一次成功的 Records 写操作保存不可变审计快照。
- Android 今日流水以记录时间为主信息，记录项管理页展示已配置目标，两个列表移除无业务含义的左侧图标。
- 为 Records 内容切换增加轻量过渡动画。

## 实施

1. 新增审计日志表和迁移；在记录项、流水的创建、修改、归档、恢复和删除事务内写入变更前后快照，并提供倒序日志 API。
2. 移除流水更新 API 与网页编辑界面；网页新增只读 Logs 页签，显示操作时间、对象、动作和变更摘要。
3. 调整 Android Records 列表：流水标题为本地记录时间，副文本显示项目、数值和可选目标；管理项摘要显示目标；使用内容淡入淡出过渡。
4. 为服务端、网页和 Android 领域格式化补充定向测试，并执行现有全量验证。

## 验收

- 每个成功写操作在同一数据库事务中生成一条包含前后快照的审计日志；失败请求不产生数据或日志。
- 网页 Entries 不再显示 Edit 或流水编辑弹窗，删除仍可用；Logs 能按最新优先显示新增、修改和删除的内容。
- Android 今日流水首行显示 `HH:mm`，管理项和流水均能显示已配置目标，列表行没有无意义图标。
- Records 内容刷新时有短暂、稳定的过渡，默认导航动画保持不变。
