# Records 管理端 Today 与每日任务

Status: planned

## 目标

让 PC 管理端成为 Today 的完整客户端，并让任务支持 `DAILY` 重复。每日任务在界面中始终只有一份定义，每个本地日期独立保存步骤完成状态；新一天自动呈现为未完成，漏做不产生逾期或待补实例，也不自动占用 Today 的 `1 + 1` 槽位。

## 已确认决策

| 关注点 | 决策 |
| --- | --- |
| PC Today | 可创建、调整、开始、回顾、额外一轮、完成步骤和结束，复用现有服务端状态机。 |
| PC 提醒 | 浏览器不增加通知或 Service Worker；Android 下次恢复或刷新时按服务端最新 revision 调度。 |
| 重复范围 | 本轮只提供 `ONCE` 与 `DAILY`，不增加周几、间隔、截止日或补做规则。 |
| 每日完成 | 稳定任务定义 + 按 ISO 本地日期保存步骤完成记录；不复制任务，不在午夜执行重置写入。 |
| 跨日 | 每日任务今天完成后进入今天的 Completed，明天自动回到 Open；未完成日期不生成数据。 |
| Today 选择 | 每日任务与一次性任务一样由用户显式选择，不自动占主任务或次任务。 |
| 模式修改 | 可在任务编辑页切换；切换后目标作用域从未完成开始，历史日期记录保留且不参与当前状态。 |

## 数据与 API

- `todo_tasks` 增加 `repeat_mode: ONCE | DAILY`，删除持久化的 `completed_at`。
- `todo_steps` 删除持久化的 `completed_at`；完成状态只从 `todo_step_completions` 派生。
- `todo_step_completions` 保存 `step_id`、`scope: ONCE | DAILY`、可空 `local_date`、`completed_at`：
  - `ONCE` 要求 `local_date IS NULL`，每个步骤至多一条。
  - `DAILY` 要求真实 ISO `local_date`，每个步骤每天至多一条。
  - 删除步骤时级联删除完成记录。
- 父任务完成时间取当前作用域全部步骤完成时间的最大值；缺少任一步骤完成记录即为未完成。
- 迁移把现有任务设为 `ONCE`，把现有已完成步骤写入 `ONCE` 完成记录，再删除旧完成列。
- 任务列表和详情必须携带显式 `localDate`。任务/步骤写操作也携带该日期，用于返回当前状态、审计父任务变化并只更新同日期的 Today。
- 创建和更新任务携带 `repeatMode`；切换模式时删除目标当前作用域的完成记录，使新模式从 Open 开始。
- 被该日期未结束计划引用的任务不能切换模式，用户必须先替换承诺或结束今天。
- 每日计划校验任务状态时固定使用计划自身 `localDate`。步骤完成只协调同一日期的 `READY/ACTIVE` 计划。
- overview 继续用 `planDate` 同时派生任务状态和返回当日计划；服务端不推断调用者时区。

## PC Today

- Workspace 导航固定为 `Overview → Today → Tasks`；Today 只操作浏览器本地日期。
- 无计划时提供第一步、必选主任务和可选次任务表单。
- `READY` 可调整承诺、完成第一步开始第一轮或结束。
- `ACTIVE` 显示当前任务、步骤、轮次和下一回顾时间；步骤可直接完成，到期后可继续、切换承诺或结束。
- `ENOUGH` 可选择尚未完成承诺开始额外一轮或结束；`ENDED` 只读。
- 所有动作使用当前 revision；冲突显示服务端错误并刷新后重试，不做客户端合并。
- Tasks 创建和编辑表单提供 `Once/Daily` 选项；Open/Completed 按浏览器本地日期解释。

## Android

- `TodoTask` 增加 `repeatMode`；任务创建和详情页提供 `Once/Daily` 选择。
- Repository 在任务、步骤读写中提交当前本地日期；Today 和任务列表继续只使用服务端派生状态。
- 每日任务不改变现有 `1 + 1`、小时回顾、提醒权限和 WorkManager 规则。
- APK 变更时递增版本并发布新的 debug 通道。

## 验收

- 现有任务迁移后仍为 `ONCE`，当前完成状态保持不变。
- 每日任务在同一天完成全部步骤后为 Completed；查询下一本地日期时同一任务和步骤为 Open，查询原日期仍保持 Completed。
- 每日任务漏做不会创建实例、逾期或失败；新一天不会自动进入 Today。
- 一次性任务仍在完成后保持 Completed，重开步骤后恢复 Open。
- Today 的主次限制、完成自动切换、四轮收口、额外一轮、revision 和删除保护对两种任务一致。
- PC 可完成 Today 全状态流程和承诺步骤；浏览器不注册通知，Android 刷新后接受 PC 写入的最新状态。
- 服务端拒绝缺少/非法本地日期、非法完成作用域、过期 revision 和跨日期计划协调。
- 迁移、API、Web、Android 单元测试、instrumentation 编译、debug 构建、lint 与 `git diff --check` 通过。
