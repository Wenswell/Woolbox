# Home 交互优化计划

## 状态

实施中。完成代码、定向测试和可行的真机检查后删除本计划，并把长期规则同步到产品说明与设计系统。

## 范围

- Home 首个内容区域显示无障碍服务权限状态；已启用使用有色成功图标，未启用使用有色提示图标。
- 未启用权限时点击权限行打开系统设置；已启用后再次点击只显示当前状态提示，不跳转。
- Global Copy 与 OLED shield 详情页移除重复的权限区域。
- 详情页的 `Start Global Copy`、`Show shield` 使用与其他内容一致的列表条目。
- Quick Settings 行由整行承担添加动作，移除右侧 `Add` 按钮；Android 12/12L 仍保持不可用并要求用户从系统编辑页添加。
- Copy History 使用目标应用名称和图标展示，列表不显示包名；存储和服务能力不变。

## 实施步骤

1. 调整 Home 权限区域、状态图标和已授权点击提示。
2. 调整工具详情页动作行与 Quick Settings 行，移除重复权限参数和 UI。
3. 复用应用图标展示组件，为 Copy History 解析应用名称和图标。
4. 更新产品、设计和开发文档中的长期规则与真机验收项。
5. 执行 Compose/Kotlin 定向编译、相关 JVM 测试、Debug 构建、差异检查，并完成可行的设备状态验证。

## 可观察验收标准

- Home 打开后，权限区域位于工具列表之前；授权状态可通过有色图标区分。
- 未授权点击权限行进入系统无障碍设置；已授权点击停留在应用并显示权限已启用提示。
- 两个详情页不再显示权限行；工具启动条目、Quick Settings 条目均按整行交互。
- Android 13 及以上点击 Quick Settings 条目发起系统添加请求；Android 12/12L 条目不可用，两个 Tile 仍可在系统编辑页手动添加。
- Copy History 每行显示目标应用图标和名称、块数、时间及预览，不显示目标包名。
- Global Copy/OLED 的服务绑定、覆盖层、目标窗口选择、Tile 执行和存储规则与修改前一致。
