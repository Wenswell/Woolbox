# 工具历史与应用配置实施计划

## 目标

为 Global Copy 增加可持久化、可编辑复制的采集历史；为 OLED shield 增加按应用记录的配置列表，并支持删除配置或启动目标应用后按记录参数显示遮罩。

完成条件：每项需求均有源码与定向测试支撑，主题文档已同步，提交前构建通过；按用户要求不执行真机验收。

## 已确认语义

- Global Copy 每次得到非空 `TextSnapshot` 时创建一条历史，不以是否复制为条件。
- 历史保留完整文本块、选择状态、两种顺序草稿与当前顺序；打开历史复用现有编辑、文本选择和复制内容。
- 历史编辑通过显式 `Save` 回写；`Copy` 只复制当前草稿并关闭弹窗。单条历史支持删除。
- OLED 配置按包名唯一；每次实际显示遮罩时固化当次参数并更新记录时间。
- OLED 控制面板的 `Save` 更新同一应用配置；删除移除该应用配置。
- OLED `Enable` 是一次性动作：启动目标应用，服务只在指定包名成为前台后按列表中的参数显示遮罩，不增加持久化启用状态。

## 方案

### Global Copy

- 使用独立 Room 数据库保存历史父记录与文本块子记录，复用项目已有 Room/KSP，不新增依赖。
- 父记录保存包名、捕获时间、两种草稿和当前顺序；子记录保存 `CopyTextBlock` 全字段与选择状态，外键级联删除。
- `ToolAccessibilityService` 在非空快照生成后异步写入，写入成功后才显示会话，确保已显示的采集均有历史。
- 将编辑状态迁移提取为纯函数，将编辑器 Compose 内容从窗口宿主中解耦：跨应用会话继续使用 `TYPE_ACCESSIBILITY_OVERLAY`，历史使用应用内全屏 Dialog。
- Global Copy 详情页显示历史入口与数量；独立历史页按捕获时间倒序展示包名、文本预览和时间。

### OLED shield

- 扩展现有 `OledShieldConfigRepository`，用 SharedPreferences 保存包名集合、五项参数和记录时间，并提供观察、删除与按时间排序能力。
- `OledShieldController.show()` 接受可选的指定参数；普通入口读取应用配置或默认值，定向入口使用命令携带的配置，两者显示成功前都记录实际参数。
- 将 `ExternalToolCommand` 改为带载荷的封闭命令；定向 OLED 命令包含包名和配置，拥有独立的目标包匹配与超时时间。
- `MainActivity` 使用 Android 34+ 的 `getLaunchIntentSenderForPackage()` 启动应用，`onStop` 后再提交定向命令。
- Manifest 只声明 `MAIN` + `LAUNCHER` 包可见性。页面通过 `PackageManager` 读取当前应用名称与图标；应用不可用时明确禁用 Enable，仍允许删除记录。
- OLED 详情页的配置列表显示应用图标、名称、透明度/宽度/高度、记录时间，以及 Enable 和 Delete 图标操作。

## 实施步骤

1. 建立 Global Copy 历史实体、DAO、Repository、映射规则与定向 JVM 测试。
2. 提取共享编辑状态和编辑器内容，接入服务采集写入、历史列表、保存、复制与删除。
3. 扩展 OLED 配置存储与测试，接入配置记录、应用元数据和列表操作。
4. 扩展工具命令与 MainActivity 启动流程，服务等待指定包名后使用对应配置显示遮罩。
5. 同步 `README.md`、产品、架构、设计与开发文档；删除本计划，执行完整 JVM 测试、Debug 构建和 `git diff --check`。

## 验收标准

| 场景 | 可观察结果 |
| --- | --- |
| Global Copy 采集 | 非空快照显示会话，并立即出现在历史列表；空快照不创建记录。 |
| 历史重开 | 文本块、选择、两种顺序和草稿与上次保存一致。 |
| 历史编辑 | `Save` 后重新打开仍显示编辑结果；`Copy` 写入当前非空草稿并关闭；删除后记录消失。 |
| OLED 首次使用 | 目标应用首次显示遮罩后，列表出现该应用及当次参数和记录时间。 |
| OLED 再次使用 | 同一应用保持一条记录，参数与记录时间更新，列表按记录时间倒序。 |
| OLED 管理 | Delete 删除配置；Enable 启动对应应用，并只在该包名前台时按记录参数显示遮罩。 |
| 应用信息 | 已安装且可启动的应用显示当前名称和图标；不可用记录明确禁用 Enable 且可删除。 |
| 回归 | 普通页面入口、两个 Tile、Global Copy 会话和 OLED 控制面板现有语义保持不变。 |

## 范围边界

- 不增加历史搜索、批量操作、自动清理、导出、同步或保留上限。
- 不保存应用图标副本；列表读取当前已安装应用的图标。
- 不兼容或迁移旧的按应用 OLED SharedPreferences 数据。
- 不新增后台任务、通知、包变化监听或启动失败后的替代路径。
