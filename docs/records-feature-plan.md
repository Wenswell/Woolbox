# Records 功能实施计划

## Goal

在现有 Android 应用中新增 `Records` 底栏目的地，迁移 `daily-record` 已验证的量化记录闭环：配置记录项、按当前时间推荐、记录数值或时长、查看单日流水和日/周目标。界面采用“周日期条 + 单日流水”，右上角进入管理页，右下角使用 `Record` 扩展 FAB。

完成条件：本文全部验收项有源码、自动测试或真机结果支撑；当前两项无障碍工具无回归；长期规则已同步到主题文档；本文随后删除。

## 决策依据

- 第一性原理：最高频目标是“立即记录一个值”，周视图只提供日期上下文，不能挤占单日内容。
- 贝叶斯判断：旧项目对记录项、推荐、记录和目标已有源码与测试，对未来日程、统计、提醒和同步没有可靠模型，因此只迁移前者。
- 奥卡姆剃刀：使用一个 Room 数据库、一个 Repository、一个 `RecordsViewModel`；不增加 DI、用例层、日历框架或独立模块。
- 无历史包袱：不导入旧 SQLite，不兼容旧字段，不保留备用存储和双写路径。

## 首版范围

### 用户入口

- 底栏顺序为 `Home`、`Records`、`Setting`，应用仍默认打开 `Home`。
- `Records` 首次进入当前周并选中今天；切换 Tab 或配置变化不重置所选日期。
- 页面右上角 `Manage` 打开独立管理路由；管理页不显示底栏和 FAB。
- 有活跃记录项时，右下角显示带图标和 `Record` 文案的扩展 FAB。
- 空库或没有活跃记录项时显示 `Create record item` 主操作，不显示不可执行的 FAB。

### 周日期条与单日流水

- 周按本地时间的周一至周日计算；支持在历史周与当前周之间分页，当前周为上限；点击周标题使用最大日期为今天的 Material DatePicker 跳转。
- 日期单元显示星期、日号和记录标记；默认选中今天，未来日期不可选且不表示日程。
- 正文展示选中日期的日目标、所在周的周目标和按本地分钟升序排列的记录。
- 进入今天时定位到最近记录；今天额外显示最多 5 个“推荐此刻”记录项。
- 记录项推荐顺序为：文字匹配、当前时间窗命中、距时间窗距离、优先级、名称。
- 目标进度求和同一记录项在周期内的记录值；日目标按本地自然日累计，周目标按周一至周日累计，达标后保留实际累计值。

### 立即记录

- FAB 打开单个 `ModalBottomSheet`，先选择记录项，再确认数值；不叠加多个 Sheet 或 Dialog。
- 选择列表默认展示“推荐此刻”，支持按名称和描述搜索。
- 数值确认预填记录项默认值，使用减号、输入框、加号按正数步进调整，并显示单位与当前目标进度。
- 数值必须是有限正数；确认后按设备当前时刻创建记录，不受当前浏览日期影响。
- 保存成功后选中今天、刷新流水与目标，并显示带 `Undo` 的 Snackbar；撤销只删除刚创建的记录。

### 记录项管理

- 管理页使用 `Active`、`Archived` 两个 Tab；支持新建、编辑、归档、恢复和永久删除。
- 记录项字段为：名称、描述、类型、默认值、步进、单位、可选目标、目标周期、推荐时间段、优先级。
- 类型只支持 `Number`、`Duration`；目标周期只支持 `Day`、`Week`。
- `Number` 默认值为 `1`、步进为 `1`、单位为 `次`且单位可编辑；`Duration` 默认值为 `30`、步进为 `1`、单位从 `秒`、`分`、`小时`中选择。
- 名称去除首尾空白后必填，并在全部记录项中忽略大小写唯一；默认值和目标值可空，填写时必须是有限正数；步进始终为有限正数。
- 推荐时间段可空，表示全天可推荐；优先级默认为 `1`，数值越大越优先。
- 推荐时间段由本地日内开始分钟、结束分钟组成，可配置多个、允许跨午夜，不支持相同起止时间。
- 归档保留历史记录并从推荐、记录选择和目标中移除；恢复后重新参与这些查询。
- 永久删除只从归档详情执行，确认框显示关联记录数量，确认后级联删除时间段和记录。
- 已产生记录后，类型和单位不可修改；需要改变计量语义时归档旧项并新建记录项。

## 数据与工程边界

### 数据模型

Room `version = 1` 使用三张表：

| 表 | 关键字段与约束 |
| --- | --- |
| `record_items` | `id`、名称、描述、类型、默认值、步进、单位、目标值/周期、优先级、归档状态、创建/更新时间；名称使用忽略大小写唯一索引。 |
| `record_windows` | `id`、`itemId`、开始分钟、结束分钟；外键级联删除。 |
| `record_entries` | `id`、`itemId`、发生时刻、固化的本地日期、本地分钟、正数值、创建时间；外键级联删除，并索引 `(localDate, localMinute)`。 |

发生时刻使用 epoch milliseconds；历史分组以写入时固化的 ISO 本地日期和本地分钟为准，设备之后切换时区不会重分组。历史展示读取当前记录项名称和单位。

### 代码归属

- 新功能归属 `app/src/main/java/com/wswensw/template/record/`，按 `model`、`data`、`ui` 分层。
- `data` 只包含 Room entity/DAO/database 和一个 Repository；Repository 暴露 `Flow` 查询与明确写操作。
- `RecordsViewModel` 组合记录项、选中日期、记录、目标和推荐，向 Compose 暴露单一不可变 UI state。
- `TemplateApp.kt` 只负责 Tab、路由和依赖接线；Records 不调用 `onLaunchTool`，不接入无障碍服务、Tile 或覆盖层。
- `TemplateSurface` 增加可选 FAB 槽；`RecordsScreen` 使用 `LazyColumn`，管理页复用现有 route scaffold 和列表组件。
- 日期计算使用 `java.time`，周分页使用 Compose Foundation `HorizontalPager`；不新增日历依赖。
- 仅新增 Room 与 KSP 所需 AndroidX/构建依赖。

## 实施步骤

1. **记录项纵切片**：加入 Room/KSP、三表 schema 和单 Repository，接入管理路由与空库入口；实现记录项新建、编辑、持久化及对应测试。
2. **立即记录纵切片**：接入 `Records` Tab、扩展 FAB 和单 Sheet 流程；实现推荐与搜索、数值确认、当前时间写入、今天流水和 Snackbar 撤销。
3. **周视图纵切片**：实现历史周分页、日期跳转、单日流水、日/周目标和“推荐此刻”，并覆盖日期、推荐与目标纯函数测试。
4. **归档纵切片**：实现 Active/Archived 列表、归档、恢复和带关联记录数量确认的永久删除。
5. **收尾**：处理加载、空数据、输入校验和旋转恢复；将已实现事实同步到 `product.md`、`architecture.md`、`design-system.md`、`development.md`、`README.md` 和 `AGENTS.md`，执行验证，删除本文后提交最终实现。

每个纵切片达到本节对应验收项后单独提交；若实现需要新增本文未定义的产品状态、依赖或跨模块能力，先暂停确认，不顺带扩展。

## 验收标准

| 场景 | 可观察结果 |
| --- | --- |
| 导航 | 底栏稳定显示三个目的地；启动仍是 Home；Records 默认当前周和今天；现有工具详情仍不显示底栏。 |
| 首个记录项 | 空库可从 Records 进入创建流程；重启应用后记录项仍存在。 |
| 记录 | FAB 按当前时间保存正数值；默认值、步进、单位正确；保存后记录和目标即时更新。 |
| 撤销 | Snackbar 的 Undo 只移除刚创建记录，列表和目标同步恢复。 |
| 推荐 | 当前时间窗内项目优先；搜索时名称前缀、名称包含、描述包含依次排序。 |
| 日期 | 周一至周日边界正确；历史记录按写入时本地日期显示；未来日期不可选。 |
| 目标 | 日目标只累计选中自然日；周目标只累计对应周；超额显示实际值。 |
| 管理 | 归档不删除历史且不再参与记录；恢复重新参与；永久删除明确记录数量并级联清除。 |
| UI | 360dp 宽度、深浅色和字体放大下无溢出或遮挡；日期单元和图标按钮触控区至少 48dp。 |
| 回归 | Global Copy、OLED shield、两个 Tile 及无障碍服务行为保持现状。 |

## 验证

- JVM 定向测试：周边界、跨午夜时间窗、推荐排序、日/周目标、数值步进和校验。
- Room instrumentation 定向测试：日期范围查询、归档过滤、创建与撤销、外键级联。
- Compose/真机定向验收：空库、创建记录项、记录 Sheet、周分页、日期跳转、旋转、深浅色、字体放大。
- 提交前一次执行 `:app:testDebugUnitTest :app:assembleDebug`、相关 instrumentation tests 和 `git diff --check`。

## 非目标

- 不实现补记或修改发生时间、历史记录编辑、任意历史删除、备注、计时器、提醒、统计、连续天数、模板库。
- 不实现未来日程、按星期重复、月热力图、导入旧数据库、导出、备份、同步、多用户或跨应用记录。
- 不迁移 TUI/CLI、键盘焦点、命令补全、Seed、终端布局和每秒时钟。
