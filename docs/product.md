# 产品说明

## 定位与范围

Woolbox 是 Android 12 及以上的工具应用。当前提供两项跨应用无障碍能力和一项单人在线 Records 能力，并用它们验证应用页面、底栏、持久化和通用 Compose 组件。

| 能力 | 结果 | 页面入口 | 快捷入口 |
| --- | --- | --- | --- |
| `Global Copy` | 读取目标应用当前窗口中的可访问文本，选择并复制到剪贴板。 | `Start Global Copy` | `Global Copy` Quick Settings Tile |
| `OLED shield` | 在目标应用上方显示可触摸的黑色遮罩。 | `Show shield` | `OLED shield` Quick Settings Tile |
| `Records` | 用模板建立当天承诺并管理量化记录；量化记录可累计，也可按指定时间保存测量值。 | `Records` 底栏 | 分区与独立路由 |

Global Copy 与 OLED 的跨应用模式共用 `Woolbox tools` 无障碍服务。服务未连接时，Global Copy 主操作不可用，OLED 主操作改为在 Woolbox 内显示遮罩；Tile 点击会打开应用。`Records` 通过 HTTPS API 访问服务端 SQLite，不依赖无障碍服务，也不使用本地记录数据库。

当前不包含 Global Copy 滚动采集、搜索、批量管理、导出、上传、同步或自动清理，以及 OLED 多配置版本、后台自动启动和独立管理页。Records 不提供离线队列、日历视图、每日以外的模板周期、标签、协作、多级步骤、精确闹钟或可配置图表。App 更新不静默安装、不跨 debug/release 更新，也不接受非 `dl.1662803.xyz` 的更新包。

## 入口语义

### Tools

Tools 首个内容区域为 `Access`，显示 `Accessibility service` 的授权状态。系统未启用时点击打开无障碍设置；系统已启用后再次点击只提示服务已启用，不重复跳转。已启用使用成功色图标，未启用使用错误色图标；详情页不重复显示该权限区域。

### 页面入口

页面主操作用于配置后直接启动工具。服务连接时，点击后 Woolbox 任务进入后台，系统恢复此前的应用；Activity 停止后才提交工具命令，目标来自恢复后的实时窗口。服务未连接时，OLED 留在当前页面并显示使用当前默认参数的应用内遮罩，不创建应用配置。OLED 已保存应用的 `Enable` 只在服务连接时可用，会先启动指定应用，再提交包含包名和配置的命令。

### Quick Settings Tile

Tile 用于不离开目标应用的快速启动。点击后系统面板收起，服务等待目标应用窗口重新成为前台再执行命令。Android 13 及以上可点击工具详情页的 `Quick settings` 整行请求添加；Android 12/12L 该行不可用，由用户在系统快捷设置编辑页手动添加。

页面主操作与 Tile 使用实时目标选择和两秒超时，不缓存历史目标包名。OLED 已保存应用命令只接受指定包名，并使用五秒超时等待目标应用启动。

### App 更新

Setting 打开时检查当前 build type 的 `latest.json`：debug 只检查、下载和安装 debug APK；release 只检查、下载和安装 release APK。Updates 显示当前构建类型和版本号。当前版本低于远端版本时，区域显示版本和大小；用户确认下载后，App 下载版本化 APK、校验大小与 SHA-256，并将通过校验的文件交给 Android 安装器。未授予“安装未知应用”权限时，App 打开对应系统设置；授权返回后用户再次确认安装。系统安装器始终要求用户确认，App 不会静默安装或绕过签名校验。

### 应用语言

Setting 的 Language 提供 `Follow system`、`English` 和 `简体中文`。选择后立即重建当前 Activity 并应用对应 Android 资源；`Follow system` 清除应用语言覆盖。Android 13 及以上与系统“应用语言”设置使用同一状态，Android 12 由 AppCompat 保存选择。应用页面、覆盖层、系统 Tile、本地状态与错误使用目标语言；用户输入的模板、记录名称与服务端错误正文保持原文。

## 状态语义

| 页面状态 | 条件 | 用户操作 |
| --- | --- | --- |
| `Not enabled` | 系统未启用无障碍服务。 | 打开 `Accessibility service` 并授权。 |
| `Waiting for service` | 系统记录已启用，但服务尚未绑定。 | 等待绑定；若持续存在，按开发文档排障。 |
| `Connected` | 服务已绑定，可以接收工具命令。 | 使用页面主操作或 Tile。 |
| `Ready` | 对应工具未运行。 | 可以启动。 |
| `Preparing` | 入口已触发，服务正在等待外部应用窗口。 | 普通入口最多等待两秒；OLED 已保存应用最多等待五秒。 |
| `Active` | 对应覆盖层已显示。 | 在覆盖层内操作或关闭。 |

同一时间只运行一个工具。启动另一工具前会关闭当前工具；再次点击处于 `Preparing` 或 `Active` 的同类 Tile 会取消或关闭该工具。

## Global Copy

### 用户流程

1. 在目标应用中打开需要复制的页面。
2. 通过 Woolbox 的 `Start Global Copy` 或 Quick Settings Tile 启动。
3. 会话默认选中全部文本块，直接显示视觉阅读顺序的可编辑草稿。
4. 可直接编辑草稿、关闭 `Reading order` 使用捕获顺序，或进入 `Select text` 调整来源文本块。
5. 文本选择即时重建两种顺序草稿，返回后继续编辑当前顺序的草稿。
6. 非空草稿写入系统剪贴板后显示成功提示，并关闭会话；关闭按钮直接结束会话。
7. 返回 Global Copy 详情页可查看每次非空采集的历史。

### 复制规则

| 状态或动作 | 输出规则 |
| --- | --- |
| `Reading order` 开启 | 默认状态；按屏幕视觉行从上到下、行内从左到右重排，同一视觉行使用空格连接。 |
| `Reading order` 关闭 | 按快照中的稳定捕获顺序输出，每个文本块占一行。 |
| 编辑 | 两种顺序分别保存草稿，往返切换不会覆盖对应草稿中的修改。文本选择变化时，两种草稿按当前选择重新生成。 |
| `Copy` | 复制当前顺序的非空编辑草稿；空白草稿时不可用。 |

只读取可见、非密码、具有非空屏幕边界且包含可访问文本的节点。相同来源与归一化文本只输出一次。目标窗口没有文本块时不会创建会话。列表用 `captureOrder` 作为从 `0` 开始的序号，副文本只显示来源值和屏幕边界值。

### 历史规则

- 非空快照在会话显示前创建独立历史；空快照不保存，同包名和相同文本也不跨次去重。
- 历史按捕获时间倒序显示目标应用图标、名称、文本块数量、文本预览和时间；列表不显示包名。
- 打开历史会重建文本块选择、两种顺序草稿和当前顺序，并进入应用内编辑路由复用同一编辑面板；删除从编辑顶栏发起，经确认 Dialog 后返回列表。
- `Save` 显式保存选择、两种草稿和当前顺序；关闭会丢弃未保存修改；`Copy` 复制当前非空草稿并关闭，不自动保存。

## OLED Shield

### 用户流程

1. 可在详情页调整并保存默认透明度、宽度和高度。
2. 服务未连接时选择 `Show shield` 可在 Woolbox 内使用遮罩；服务连接后，可在目标应用中通过 `Show shield` 或 Quick Settings Tile 启动。
3. 遮罩立即使用该应用的已保存配置；没有应用配置时使用当前默认值。
4. 遮罩显示成功后，详情页的 `Saved apps` 按包名新增或更新该应用、当次参数和记录时间。
5. 长按遮罩打开控制面板。
6. 调整透明度、宽度、高度或拖动面板；选择 `Save` 更新当前应用配置。
7. `Close` 只关闭控制面板，`Hide shield` 关闭遮罩和面板。
8. 在 `Saved apps` 中可删除配置，或选择 `Enable` 启动目标应用并按该条参数显示遮罩。

### 配置规则

| 参数 | 默认值 | 有效范围 | 作用 |
| --- | ---: | ---: | --- |
| 透明度 | `100%` | `1%..100%` | 黑色遮罩的不透明程度。 |
| 宽度 | `100%` | `1%..100%` | 相对显示区域宽度。 |
| 高度 | `15%` | `1%..100%` | 相对显示区域高度。 |
| 面板 X | `8%` | `0%..100%` | 面板在可移动横向范围内的位置。 |
| 面板 Y | `45%` | `0%..100%` | 面板在可移动纵向范围内的位置。 |

遮罩固定从显示区域左上角开始并拦截覆盖范围内的触摸。应用内模式只覆盖 Woolbox 的应用窗口；无障碍模式使用系统级窗口并覆盖状态栏和显示刘海区域。屏幕尺寸或方向变化后，遮罩尺寸和面板位置按百分比重新计算。

每个包名只保留一条配置。再次显示遮罩会用实际参数更新配置和记录时间；控制面板 `Save` 更新参数但保留本次打开时间。列表读取当前应用名称和图标；应用不可用时禁用 `Enable`，仍可删除配置。

## Records

### 用户流程

1. 首次使用在 Setting 的 `Records connection` 配置 Basic Auth 用户名和密码；凭据使用 Android Keystore 加密保存。
2. 根列表固定为 **Today → Templates → Routines → Measurement**。Today 是执行区；Templates 只保存可复用定义；Routines 与 Measurement 不进入 Today 状态判断。
3. Today 未规划时从活跃模板选择一个主承诺、最多一个不同的次承诺，并填写 `firstMove`。系统复制模板标题、周期和步骤为当天实例；完成第一步后才开始第一轮。
4. 每轮开始约 60 分钟后提醒回顾。回顾不输入总结，只能继续当前承诺、切换到另一未完成承诺或结束今天。第四轮及以后每次回顾后暂停；有未完成实例时可继续一轮，全部完成时可从模板添加承诺。
5. 初始计划只在 `READY` 可调整。跨本地日期后旧计划不继承；Daily 模板在选择器中优先显示，但不会自动创建实例。同一模板当天可多次添加。
6. Templates 保存标题、步骤和 `MANUAL/DAILY` 周期，没有完成状态。Android 管理活跃模板的创建、整体编辑和归档；PC 另提供归档恢复与永久删除。
7. Routines 显示今日累计并通过记录 Sheet 写入；Measurement 显示最新值并通过 24 小时预览 Sheet 的离散 Slider 录入。成功写入仍提供短时 `Undo`。
8. PC 管理页固定为 `Overview`、`Today`、`Templates`、`Accumulate`、`Measurement`、`Entries`、`Activity`；Today 可切换任意本地日期，处理全部实例步骤，并执行开始、提前回顾、即时切换、添加承诺、继续一轮、结束和重置，Android 刷新后读取同一服务端状态。

### 每日承诺规则

- 每个 ISO 本地日期至多一份计划，状态为 `READY`、`ACTIVE`、`PAUSED` 或 `ENDED`；`REVIEW_DUE` 由 `ACTIVE` 和 `nextReviewAt` 派生。`PAUSED` 必须带 `COMMITMENTS_COMPLETED` 或 `TARGET_REACHED` 原因。
- 初始主模板必填，次模板可空且不得与主模板相同。创建计划时生成 `PRIMARY` 和可选 `SECONDARY` 快照；之后模板编辑或归档不改变这些实例。
- 完成当前实例后自动切到下一未完成实例；全部完成则进入 `PAUSED + COMMITMENTS_COMPLETED`。该状态只提供添加承诺；新增 `ADDITIONAL` 实例后立即恢复 `ACTIVE`。步骤完成、添加实例和继续一轮都不增加轮次。
- 第四次及后续回顾进入 `PAUSED + TARGET_REACHED`。仍有未完成实例时只提供“继续一轮”；没有未完成实例时只提供“添加承诺”。轮次只在到期回顾或 PC 提前回顾时增加。
- 在 `COMMITMENTS_COMPLETED` 暂停中重新打开实例：第一步未完成则恢复 `READY`，否则恢复 `ACTIVE` 并从操作时刻计算 60 分钟。`ENDED` 不自动恢复。
- 计划与实例步骤写操作携带当前 revision；服务端拒绝重复、过期或非法状态操作。开始、继续一轮和添加承诺要求通知可用；活动中关闭通知后只提供恢复通知或结束今天。
- PC 可提前完成当前轮，或不增加轮次地即时切换未完成实例。`Reset to Ready` 保留第一步、实例快照及其完成状态，只重置计划执行状态。

### 模板规则

- 模板保存标题、`MANUAL/DAILY` 周期、归档状态和至少一个有固定位序的一级步骤。标题与步骤保存前去除首尾空白且不能为空；步骤随表单整体替换。
- 模板不保存完成状态、计划日期、优先级或标签。`DAILY` 只影响选择排序和提示，不触发自动加入、补做或午夜重置。
- 归档模板不进入 Today 选择器；永久删除只接受已归档模板。既有 Today 实例保留快照，模板删除后其 `templateId` 可为空。

### Record items

记录项有 `ACCUMULATE` 与 `MEASUREMENT` 两种模式。

| 模式 | 规则 | 页面行为 |
| --- | --- | --- |
| `ACCUMULATE` | 支持 `Number` 或 `Duration`；流水、默认值、步进和目标均为有限正数。可设置日/7 日目标。 | 显示今日累计并通过记录 Sheet 写入当前时刻的流水。 |
| `MEASUREMENT` | 固定为 `Number`；单位、最小值、最大值和步进必填，边界为有限数且最小值小于最大值。区间必须被步进整除，流水只能是闭区间内的步进值；不支持默认值和目标。 | 显示最新值和时间；点卡在预览 Sheet 显示近 24 小时原始时间序列、流水和滑块录入。 |

- 名称、描述和单位保存前去除首尾空白；名称必填并在全部记录项中忽略大小写唯一。已有流水后，模式、数值类型和单位不可变；Measurement 的最小值、最大值和步进也不可变。
- Android 端累计表单固定 `ACCUMULATE`（含数值类型、默认值、目标和优先级）；测量表单固定 `MEASUREMENT` + `Number`（含最小值、最大值、步进、单位和优先级，无默认值与目标）。两类表单都不配置时间段。标题为 `New/Edit accumulate` 与 `New/Edit measurement`。
- 测量发生时间固定为提交时的当前设备时间。客户端提交 `occurredAt`、`localDate`、`localMinute` 与滑块值；预览只显示最近 24 小时，图表使用真实发生时间和原始数据点，不补零、聚合或平滑。点位标记显示发生时间和值；只有成功提交后的短时 `Undo` 可以删除该条流水。
### 在线数据规则

- 服务端的记录项、模板、DailyPlan、Today 实例及审计表是唯一事实来源；App 与 PC 管理页均通过 HTTPS API 读写。
- App 只在当前进程保存最近一次成功的根页快照，不写入本地记录数据库。首次加载显示 loading；底栏切换立即显示快照；恢复前台时刷新，成功写入后串行获取新快照。写入结果与刷新结果独立：写入成功后立即返回成功；刷新失败时保留已有快照并显示重试入口。
- 服务端统一执行名称忽略大小写唯一、记录模式和值规则、Measurement 闭区间步进、归档项不可新增流水、已有流水后模式/数值类型/单位/Measurement 范围不可变、永久删除仅归档项等规则。手动时间段字段不属于 API，携带该字段的写请求会被拒绝。
- 每次实际创建、修改、归档、恢复或删除记录项与模板，创建或删除流水，修改实例步骤，以及创建、调整、切换、添加承诺、重置或结束每日计划，均在同一事务写入审计日志；逐轮回顾不单独保存正文。无变化写入和失败请求不产生业务数据或日志。
- 流水查询支持日期范围、记录项和模式筛选并按记录时间倒序；另提供测量记录的最新流水。服务端不依赖自身时区，客户端提交的 `occurredAt`、`localDate` 和 `localMinute` 原样保存。

## 共同关闭规则

以下任一事件会取消待执行命令并关闭活动覆盖层：

- Woolbox 自身重新成为前台应用。
- 前台目标切换到其他包名。
- 无法继续解析外部应用窗口。
- 无障碍服务解绑或销毁。

关闭时必须释放全部覆盖层窗口、会话数据和活动状态，并同步两个 Tile 的显示状态。

## 验收标准

- Debug APK 可安装并启动于 Android 12（API 31）设备。
- Tools 首个区域为 `Access`；未授权时显示错误色图标并可打开设置，授权后显示成功色图标，再次点击只提示已启用且不跳转。
- Global Copy 与 OLED shield 详情页不显示重复权限栏；顶部 `Start Global Copy`/`Show shield` 使用列表条目，Quick Settings 在支持请求时整行可点击且无右侧 `Add` 按钮。
- 授权后两个详情页显示 `Connected`，页面主操作可用。
- 未授权时 OLED 主操作仍可用，可在 Woolbox 内显示、调整和关闭遮罩，不产生应用配置。
- 两个页面入口均使 Woolbox 进入后台，并对恢复的目标应用启动正确工具。
- 两个 Tile 均在系统面板收起后对恢复的目标应用启动正确工具。
- 同类工具连续触发时只保留一个实例，并按再次触发关闭；不同工具连续触发时只保留最后触发的工具。
- Global Copy 默认进入编辑页并开启 `Reading order`；文本选择、两种草稿保留、空白禁用、剪贴板写入和关闭行为符合上述规则。
- Global Copy 非空采集立即出现在历史；历史重开、显式保存、复制和删除符合上述规则。
- Copy History 每行显示目标应用图标和名称，不显示目标包名；应用不可用时使用不可用状态名称和通用图标。
- OLED shield 的默认配置、按应用记录、应用图标、删除、定向启用、长按面板、实时调整、保存和关闭符合上述规则。
- OLED 的无障碍覆盖层从完整显示区域左上角计算尺寸；顶部遮罩覆盖状态栏和显示刘海区域。
- Records 配置凭据后可从空库创建并编辑服务端记录项；无网络时显示可重试错误且不产生本地记录数据。
