# 产品说明

## 定位与范围

Template 是 Android 12 及以上的工具应用。当前提供两项跨应用无障碍能力和一项本地量化记录能力，并用它们验证应用页面、底栏、持久化和通用 Compose 组件。

| 能力 | 结果 | 页面入口 | 快捷入口 |
| --- | --- | --- | --- |
| `Global Copy` | 读取目标应用当前窗口中的可访问文本，选择并复制到剪贴板。 | `Start Global Copy` | `Global Copy` Quick Settings Tile |
| `OLED shield` | 在目标应用上方显示可触摸的黑色遮罩。 | `Show shield` | `OLED shield` Quick Settings Tile |
| `Records` | 管理量化记录项，并按当前时间写入今天的数值或时长。 | `Records` 底栏 | 页面项目行 |

Global Copy 与 OLED 的跨应用模式共用 `Template tools` 无障碍服务。服务未连接时，Global Copy 主操作不可用，OLED 主操作改为在 Template 内显示遮罩；Tile 点击会打开应用。`Records` 通过 HTTPS API 访问服务端 SQLite，不依赖无障碍服务，也不使用本地记录数据库。

当前不包含 Global Copy 滚动采集、搜索、批量管理、导出、上传、同步或自动清理，以及 OLED 多配置版本、后台自动启动和独立管理页。Android Records 界面只展示今天的流水和活跃项目标进度，并基于近 90 天流水计算项目日连击；服务端管理页提供日期范围、归档项和流水批量管理，不提供提醒。

## 入口语义

### Home

Home 首个内容区域为 `Access`，显示 `Accessibility service` 的授权状态。系统未启用时点击打开无障碍设置；系统已启用后再次点击只提示服务已启用，不重复跳转。已启用使用成功色图标，未启用使用错误色图标；详情页不重复显示该权限区域。

### 页面入口

页面主操作用于配置后直接启动工具。服务连接时，点击后 Template 任务进入后台，系统恢复此前的应用；Activity 停止后才提交工具命令，目标来自恢复后的实时窗口。服务未连接时，OLED 留在当前页面并显示使用当前默认参数的应用内遮罩，不创建应用配置。OLED 已保存应用的 `Enable` 只在服务连接时可用，会先启动指定应用，再提交包含包名和配置的命令。

### Quick Settings Tile

Tile 用于不离开目标应用的快速启动。点击后系统面板收起，服务等待目标应用窗口重新成为前台再执行命令。Android 13 及以上可点击工具详情页的 `Quick settings` 整行请求添加；Android 12/12L 该行不可用，由用户在系统快捷设置编辑页手动添加。

页面主操作与 Tile 使用实时目标选择和两秒超时，不缓存历史目标包名。OLED 已保存应用命令只接受指定包名，并使用五秒超时等待目标应用启动。

## 状态语义

| 页面状态 | 条件 | 用户操作 |
| --- | --- | --- |
| `Not enabled` | 系统未启用无障碍服务。 | 打开 `Accessibility service` 并授权。 |
| `Waiting for service` | 系统记录已启用，但服务尚未绑定。 | 等待绑定；若持续存在，按开发文档排障。 |
| `Connected` | 服务已绑定，可以接收工具命令。 | 使用页面主操作或 Tile。 |
| `Ready` | 对应工具未运行。 | 可以启动。 |
| `Preparing` | 入口已触发，服务正在等待外部应用窗口。 | 普通入口最多等待两秒；OLED 已保存应用最多等待五秒。 |
| `Active` | 对应覆盖层已显示。 | 在覆盖层内操作或关闭。 |

同一时间只运行一个工具。启动另一工具前会关闭当前工具；再次点击处于 `Preparing` 或 `Active` 的同类 Tile 会取消或关闭该工具。

## Global Copy

### 用户流程

1. 在目标应用中打开需要复制的页面。
2. 通过 Template 的 `Start Global Copy` 或 Quick Settings Tile 启动。
3. 会话默认选中全部文本块，直接显示视觉阅读顺序的可编辑草稿。
4. 可直接编辑草稿、关闭 `Reading order` 使用捕获顺序，或进入 `Select text` 调整来源文本块。
5. 文本选择即时重建两种顺序草稿，返回后继续编辑当前顺序的草稿。
6. 非空草稿写入系统剪贴板后显示成功提示，并关闭会话；关闭按钮直接结束会话。
7. 返回 Global Copy 详情页可查看每次非空采集的历史。

### 复制规则

| 状态或动作 | 输出规则 |
| --- | --- |
| `Reading order` 开启 | 默认状态；按屏幕视觉行从上到下、行内从左到右重排，同一视觉行使用空格连接。 |
| `Reading order` 关闭 | 按快照中的稳定捕获顺序输出，每个文本块占一行。 |
| 编辑 | 两种顺序分别保存草稿，往返切换不会覆盖对应草稿中的修改。文本选择变化时，两种草稿按当前选择重新生成。 |
| `Copy` | 复制当前顺序的非空编辑草稿；空白草稿时不可用。 |

只读取可见、非密码、具有非空屏幕边界且包含可访问文本的节点。相同来源与归一化文本只输出一次。目标窗口没有文本块时不会创建会话。列表用 `captureOrder` 作为从 `0` 开始的序号，副文本只显示来源值和屏幕边界值。

### 历史规则

- 非空快照在会话显示前创建独立历史；空快照不保存，同包名和相同文本也不跨次去重。
- 历史按捕获时间倒序显示目标应用图标、名称、文本块数量、文本预览和时间，单条记录可删除；列表不显示包名。
- 打开历史会重建文本块选择、两种顺序草稿和当前顺序，并在应用内显示同一编辑面板。
- `Save` 显式保存选择、两种草稿和当前顺序；关闭会丢弃未保存修改；`Copy` 复制当前非空草稿并关闭，不自动保存。

## OLED Shield

### 用户流程

1. 可在详情页调整并保存默认透明度、宽度和高度。
2. 服务未连接时选择 `Show shield` 可在 Template 内使用遮罩；服务连接后，可在目标应用中通过 `Show shield` 或 Quick Settings Tile 启动。
3. 遮罩立即使用该应用的已保存配置；没有应用配置时使用当前默认值。
4. 遮罩显示成功后，详情页的 `Saved apps` 按包名新增或更新该应用、当次参数和记录时间。
5. 长按遮罩打开控制面板。
6. 调整透明度、宽度、高度或拖动面板；选择 `Save` 更新当前应用配置。
7. `Close` 只关闭控制面板，`Hide shield` 关闭遮罩和面板。
8. 在 `Saved apps` 中可删除配置，或选择 `Enable` 启动目标应用并按该条参数显示遮罩。

### 配置规则

| 参数 | 默认值 | 有效范围 | 作用 |
| --- | ---: | ---: | --- |
| 透明度 | `100%` | `1%..100%` | 黑色遮罩的不透明程度。 |
| 宽度 | `100%` | `1%..100%` | 相对显示区域宽度。 |
| 高度 | `15%` | `1%..100%` | 相对显示区域高度。 |
| 面板 X | `8%` | `0%..100%` | 面板在可移动横向范围内的位置。 |
| 面板 Y | `45%` | `0%..100%` | 面板在可移动纵向范围内的位置。 |

遮罩固定从显示区域左上角开始并拦截覆盖范围内的触摸。应用内模式只覆盖 Template 的应用窗口；无障碍模式使用系统级窗口并覆盖状态栏和显示刘海区域。屏幕尺寸或方向变化后，遮罩尺寸和面板位置按百分比重新计算。

每个包名只保留一条配置。再次显示遮罩会用实际参数更新配置和记录时间；控制面板 `Save` 更新参数但保留本次打开时间。列表读取当前应用名称和图标；应用不可用时禁用 `Enable`，仍可删除配置。

## Records

### 用户流程

1. 首次使用在 Setting 的 `Records connection` 配置 Basic Auth 用户名和密码；凭据使用 Android Keystore 加密保存。
2. 底栏选择 `Records`；没有活跃记录项时，通过 `Create record item` 进入新建页。
3. 顶部 `Goals` 与 `Manage` 图标分别打开目标页和活跃记录项管理页；管理页通过 `New` 新建，选择已有项进行编辑。
4. 主页显示日期、全部焦点目标和快速记录卡片。焦点目标按优先级和名称排序并横向排列；日目标使用圆形进度，周目标使用横向进度。快速记录卡片只显示首字符图标、裁剪该字符后的名称、说明和今日累计，不重复目标进度。
5. `Goals` 页面按 `Daily`、`Weekly` 分组展示全部当前目标。焦点目标、目标列表项和快速记录卡片均可打开项目专属单阶段 Sheet；Sheet 使用首字符图标和裁剪后的名称，目标信息仅在对应周期进度中展示一次，今日流水独立列出，数值输入预填默认值并可按步进增减。
6. 确认后由客户端提交设备当前时刻、固化本地日期和分钟；成功后 Sheet 关闭，页面底部短时提示本次记录并提供 `Undo`，点击后删除刚创建的流水。
7. 网络失败时 Sheet 保持打开并显示错误，不写入本地记录数据，也不显示成功提示。
8. PC 管理页的 `Entries` 仅用于筛选和批量删除流水；`Logs` 显示每次成功写操作的对象、动作、时间和变更内容。

### 记录项与推荐规则

- 字段包括名称、描述、数值类型、可选默认值、步进、单位、可选日/周目标、推荐时间段和优先级。类型为 `Number` 或 `Duration`，时长单位限定为秒、分、小时。
- 名称、描述和单位保存前去除首尾空白；名称必填并在全部记录项中忽略大小写唯一，单位必填。默认值、步进和目标填写时必须为有限正数。
- 推荐时间段使用本地日内分钟，起止时间不能相同，重复区间无效；跨午夜区间按连续时间段参与推荐。
- 空搜索最多显示五项，依次按当前时间段命中、距时间段距离、优先级和名称排序。搜索时先按名称前缀、名称包含和描述包含排序，再应用时间规则。
- 记录值必须为有限正数。Android 编辑页始终禁用类型和单位，新建页允许配置；服务端在记录项已有流水时拒绝修改类型和单位。名称、描述、默认值、步进、目标、时间段和优先级仍可编辑。
- Android Records 主页显示 `Today`、当前日期、`Goals` 和 `Manage` 图标入口；有活跃目标时在标题下显示今日目标完成总览（完成数/总数、进度条，全部完成时为 `All goals done`）。活跃项按优先级降序、名称升序排列；主页焦点区横向展示全部有目标的活跃项，卡片宽度为可用宽度约 `82%` 且不超过 `300dp`，始终露出后续内容，区标题显示 `done/total`。日目标累计当天流水并使用圆形进度，周目标累计周一至周日流水并使用横向进度；达到目标后同时显示完成图标和文案。`Goals` 页面按周期分组显示全部当前目标。快速记录卡片前导：无目标用首字符圆标，有目标用迷你进度环；今日已记或达标时用填充色区分，尾部显示今日累计 `值 单位`，达标标签为 `Done`。标题去掉首个 Unicode 字符（支持文字、单码点 emoji 和组合字符）。项目 Sheet 使用同一首字符图标和裁剪后的名称，展示一次对应周期目标进度、今日流水（时刻与数值）及数值输入；项目日连击：某日存在至少一条流水即算活跃；当前连击含今天宽限（今天未记可从昨天起算），最佳连击取近 90 天窗口内最长连续；主页 Focus 卡与快速记录卡展示 current，若 best>current 同时展示 best。确认成功后若本次使目标首次达标，Snackbar 为 `Goal reached · 名称`，否则为 `Recorded 名称.`，均提供 `Undo`。Android 管理页只编辑活跃项；PC 管理页可筛选活跃/归档项、批量归档或恢复，永久删除只接受归档项。

### 在线数据规则

- 服务端是 `record_items`、`record_windows`、`record_entries` 和 `record_audit_logs` 的唯一事实来源；App 与 PC 管理页均通过 HTTPS API 读写。
- 服务端统一执行名称忽略大小写唯一、正数、时间段、归档项不可新增流水、已有流水后类型和单位不可变、永久删除仅归档项等规则。
- 每次成功创建、修改、归档、恢复或删除记录项，以及创建或删除流水，均在同一事务写入一条包含变更前后快照的审计日志；失败请求不产生业务数据或日志。日志按最新优先提供游标分页查询。
- 流水查询支持日期范围和记录项筛选并按记录时间倒序；成功写入后客户端刷新当前查询。服务端不依赖自身时区，客户端提交的 `occurredAt`、`localDate` 和 `localMinute` 原样保存。

## 共同关闭规则

以下任一事件会取消待执行命令并关闭活动覆盖层：

- Template 自身重新成为前台应用。
- 前台目标切换到其他包名。
- 无法继续解析外部应用窗口。
- 无障碍服务解绑或销毁。

关闭时必须释放全部覆盖层窗口、会话数据和活动状态，并同步两个 Tile 的显示状态。

## 验收标准

- Debug APK 可安装并启动于 Android 12（API 31）设备。
- Home 首个区域为 `Access`；未授权时显示错误色图标并可打开设置，授权后显示成功色图标，再次点击只提示已启用且不跳转。
- Global Copy 与 OLED shield 详情页不显示重复权限栏；顶部 `Start Global Copy`/`Show shield` 使用列表条目，Quick Settings 在支持请求时整行可点击且无右侧 `Add` 按钮。
- 授权后两个详情页显示 `Connected`，页面主操作可用。
- 未授权时 OLED 主操作仍可用，可在 Template 内显示、调整和关闭遮罩，不产生应用配置。
- 两个页面入口均使 Template 进入后台，并对恢复的目标应用启动正确工具。
- 两个 Tile 均在系统面板收起后对恢复的目标应用启动正确工具。
- 同类工具连续触发时只保留一个实例，并按再次触发关闭；不同工具连续触发时只保留最后触发的工具。
- Global Copy 默认进入编辑页并开启 `Reading order`；文本选择、两种草稿保留、空白禁用、剪贴板写入和关闭行为符合上述规则。
- Global Copy 非空采集立即出现在历史；历史重开、显式保存、复制和删除符合上述规则。
- Copy History 每行显示目标应用图标和名称，不显示目标包名；应用不可用时使用不可用状态名称和通用图标。
- OLED shield 的默认配置、按应用记录、应用图标、删除、定向启用、长按面板、实时调整、保存和关闭符合上述规则。
- OLED 的无障碍覆盖层从完整显示区域左上角计算尺寸；顶部遮罩覆盖状态栏和显示刘海区域。
- Records 配置凭据后可从空库创建并编辑服务端记录项；无网络时显示可重试错误且不产生本地记录数据。
- Android 新建记录后 PC 刷新可见；PC Entries 可删除但不可编辑，Logs 可查看每次成功写操作的变更快照；Android 主页焦点全量横向展示、日/周目标差异、项目卡片今日累计、Sheet 信息去重、流水时刻、正数校验、步进、成功收起和短时撤销符合上述规则。
- 工具启动和关闭过程中无障碍服务保持绑定；目标切换和服务解绑不残留窗口。
