# 产品说明

## 定位与范围

Template 是 Android 14 及以上的无障碍工具应用。当前提供两项可跨应用运行的能力，并用它们验证应用页面、底栏和通用 Compose 组件。

| 工具 | 结果 | 页面入口 | 快捷入口 |
| --- | --- | --- | --- |
| `Global Copy` | 读取目标应用当前窗口中的可访问文本，选择并复制到剪贴板。 | `Start Global Copy` | `Global Copy` Quick Settings Tile |
| `OLED shield` | 在目标应用上方显示可触摸的黑色遮罩。 | `Show shield` | `OLED shield` Quick Settings Tile |

两项工具共用 `Template tools` 无障碍服务。服务未连接时，页面主操作不可用；Tile 点击会打开应用。

当前不包含 Global Copy 滚动采集、历史、日志、导出、上传、永驻通知，以及 OLED 配置列表和独立管理页。

## 入口语义

### 页面入口

页面入口用于配置后直接启动工具。点击主操作后，Template 任务进入后台，系统恢复此前的应用；Activity 停止后才提交工具命令，目标来自恢复后的实时窗口。

### Quick Settings Tile

Tile 用于不离开目标应用的快速启动。点击后系统面板收起，服务等待目标应用窗口重新成为前台再执行命令。Tile 可从各工具详情页的 `Add` 按钮请求添加。

页面与 Tile 使用同一目标选择、准备状态和超时规则。两种入口都不会缓存历史目标包名。

## 状态语义

| 页面状态 | 条件 | 用户操作 |
| --- | --- | --- |
| `Not enabled` | 系统未启用无障碍服务。 | 打开 `Accessibility service` 并授权。 |
| `Waiting for service` | 系统记录已启用，但服务尚未绑定。 | 等待绑定；若持续存在，按开发文档排障。 |
| `Connected` | 服务已绑定，可以接收工具命令。 | 使用页面主操作或 Tile。 |
| `Ready` | 对应工具未运行。 | 可以启动。 |
| `Preparing` | 入口已触发，服务正在等待外部应用窗口。 | 最多等待两秒。 |
| `Active` | 对应覆盖层已显示。 | 在覆盖层内操作或关闭。 |

同一时间只运行一个工具。启动另一工具前会关闭当前工具；再次点击处于 `Preparing` 或 `Active` 的同类 Tile 会取消或关闭该工具。

## Global Copy

### 用户流程

1. 在目标应用中打开需要复制的页面。
2. 通过 Template 的 `Start Global Copy` 或 Quick Settings Tile 启动。
3. 会话默认选中全部文本块，可逐项选择、清空或再次全选。
4. 选择 `Copy capture`、`Copy reordered` 或 `Edit before copy`。
5. 文本写入系统剪贴板后显示成功提示，并关闭会话。

### 复制规则

| 动作 | 输出规则 |
| --- | --- |
| `Copy capture` | 按快照中的稳定捕获顺序输出，每个文本块占一行。 |
| `Copy reordered` | 按屏幕视觉行从上到下、行内从左到右重排；同一视觉行使用空格连接。 |
| `Edit before copy` | 默认显示捕获顺序草稿；`Reading order` 可切换到重排草稿。复制非空编辑结果后关闭会话。 |

只读取可见、非密码、具有非空屏幕边界且包含可访问文本的节点。相同来源与归一化文本只输出一次。目标窗口没有文本块时不会创建会话。列表用 `captureOrder` 作为从 `0` 开始的序号，副文本只显示来源值和屏幕边界值。

## OLED Shield

### 用户流程

1. 可在详情页调整并保存默认透明度、宽度和高度。
2. 在目标应用中通过 `Show shield` 或 Quick Settings Tile 启动。
3. 遮罩立即使用该应用的已保存配置；没有应用配置时使用当前默认值。
4. 长按遮罩打开控制面板。
5. 调整透明度、宽度、高度或拖动面板；选择 `Save` 保存到当前目标应用。
6. `Close` 只关闭控制面板，`Hide shield` 关闭遮罩和面板。

### 配置规则

| 参数 | 默认值 | 有效范围 | 作用 |
| --- | ---: | ---: | --- |
| 透明度 | `100%` | `1%..100%` | 黑色遮罩的不透明程度。 |
| 宽度 | `100%` | `1%..100%` | 相对显示区域宽度。 |
| 高度 | `15%` | `1%..100%` | 相对显示区域高度。 |
| 面板 X | `8%` | `0%..100%` | 面板在可移动横向范围内的位置。 |
| 面板 Y | `45%` | `0%..100%` | 面板在可移动纵向范围内的位置。 |

遮罩固定从显示区域左上角开始并拦截覆盖范围内的触摸。屏幕尺寸或方向变化后，遮罩尺寸和面板位置按百分比重新计算。

## 共同关闭规则

以下任一事件会取消待执行命令并关闭活动覆盖层：

- Template 自身重新成为前台应用。
- 前台目标切换到其他包名。
- 无法继续解析外部应用窗口。
- 无障碍服务解绑或销毁。

关闭时必须释放全部覆盖层窗口、会话数据和活动状态，并同步两个 Tile 的显示状态。

## 验收标准

- 授权后两个详情页显示 `Connected`，页面主操作可用。
- 两个页面入口均使 Template 进入后台，并对恢复的目标应用启动正确工具。
- 两个 Tile 均在系统面板收起后对恢复的目标应用启动正确工具。
- Global Copy 的选择、两种排序、编辑复制、剪贴板写入和关闭行为符合上述规则。
- OLED shield 的默认配置、按应用加载、长按面板、实时调整、拖动、保存和关闭行为符合上述规则。
- 工具启动和关闭过程中无障碍服务保持绑定；目标切换和服务解绑不残留窗口。
