# Today 额外一轮条件修复计划

状态：实施中

## 问题

当前 `extra-round` 只检查计划为 `ENOUGH` 且存在未完成承诺。`ENOUGH + COMMITMENTS` 后重新打开步骤时，计划没有恢复执行状态，界面因此把纠错错误显示为“开始额外一轮”。

## 规则

- 额外一轮只允许 `ENOUGH + ROUNDS`，即完成四轮后主动继续。
- `ENOUGH + COMMITMENTS` 中的承诺重新变为未完成时，清空完成原因并恢复原计划。
- 第一动作尚未完成时恢复 `READY`；第一动作已完成时恢复 `ACTIVE`，当前任务为重新打开的承诺，下一次回顾为操作时刻加 60 分钟。
- `ENDED` 不因任务变化恢复。

## 范围

- 修改服务端状态协调与 `extra-round` 校验。
- Android 和 PC 只在 `ENOUGH + ROUNDS` 显示额外一轮入口。
- 增补状态转换和入口测试，同步产品、架构、设计与开发文档。
- Android 递增版本；先部署服务端，再发布 debug APK。

## 验收

- 完成四轮且仍有未完成承诺时可开始额外一轮。
- `COMMITMENTS` 原因不能调用额外一轮。
- 开始前完成又重新打开承诺时恢复 `READY`。
- 开始后完成又重新打开承诺时恢复 `ACTIVE`，轮次不变，回顾时间重新计算。
- PC 与 Android 在承诺完成状态不显示额外一轮入口。
