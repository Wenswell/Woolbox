# Records 目标与图标计划

状态：进行中

## 范围

- 每个记录项保存一个固定 Material 图标键，并在 Android 和 PC 管理端选择、展示和审计。
- Android Records 顶部显示已配置日/周目标的当前累计值和线性进度。
- Android 流水行采用左侧项目图标与内容、右侧记录时间的习惯记录布局。

## 实施

1. 为记录项增加 `iconKey`，以迁移默认值保留已有数据；服务端校验固定图标集合并使审计快照包含该字段。
2. Android 使用 Material Icons Extended 提供固定图标选择器；网页记录项表单提供同一集合。
3. 刷新 Android Records 时，为日目标计算当天流水总和，为周目标查询本周流水总和；顶部以线性进度显示累计值、目标和周期。
4. 调整流水行信息层级，并补充服务端、网页和 Android 领域规则测试。

## 验收

- 旧记录项迁移后获得默认图标；新建和编辑可选择图标，API 拒绝未知键。
- 日/周目标显示正确累计值，进度达到或超过目标时填满；无目标时不显示目标区。
- 流水行左侧显示项目图标与内容，右侧显示 `HH:mm`，新增流水后的动画保持可见。
